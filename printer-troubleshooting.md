# Printer Troubleshooting

## Purpose

This guide outlines a basic troubleshooting process for common workplace printer issues.

The goal is to determine whether the problem is related to the user's device, the printer itself, the network connection, the print queue, or a larger hardware issue.

## Common Symptoms

A user may report:

* Printer is offline
* Print job is stuck
* Document does not print
* Wrong printer is selected
* Poor print quality
* Paper jam
* Printer cannot be found
* Multiple users cannot print

## Troubleshooting Steps

### 1. Confirm the Problem

Ask the user:

* Which printer are you trying to use?
* What happens when you try to print?
* Do you see an error message?
* Has the printer worked for you before?
* Are other users able to print?

This helps determine whether the issue is isolated to one user or affects the shared printer.

### 2. Confirm the Correct Printer

Check that the correct printer is selected.

In offices with multiple printers, users may accidentally send a document to another device or an old printer connection.

### 3. Check Printer Status

Confirm that the printer is powered on and does not display an error.

Check for:

* Paper jams
* Empty paper trays
* Low toner or ink
* Open printer doors
* Hardware warning messages

### 4. Check the Print Queue

Review the print queue for stalled or failed jobs.

If appropriate, cancel the failed job and attempt to print again.

### 5. Check Connectivity

For a network printer, confirm that the user's device is connected to the workplace network.

If other users also cannot print, the issue may involve the printer's network connection rather than one computer.

### 6. Restart When Appropriate

Restart the printer if normal workplace procedures allow it.

The user's computer may also be restarted if the issue appears isolated to that device.

### 7. Test the Printer

Send a simple test page or small document.

If the test prints successfully, try the original document again.

## Escalation

Escalate the issue when:

* Multiple users cannot access the printer
* Hardware appears damaged
* The printer repeatedly goes offline
* Network configuration may be involved
* Administrative access is required
* Error messages continue after standard troubleshooting
* A vendor or printer technician may be required

Document the symptoms and troubleshooting steps before escalating.

## Example Ticket Notes

**Issue:** User unable to print to shared office printer.

**Troubleshooting completed:** Confirmed correct printer selection, checked printer status, reviewed print queue, cleared stalled job, and sent test page.

**Result:** Test page printed successfully.

**Resolution:** User retried original document and printing resumed normally.

## Key Takeaway

Printer problems can originate from the user device, print queue, network, or printer hardware. Checking each layer in a logical order makes troubleshooting faster and easier to document.
