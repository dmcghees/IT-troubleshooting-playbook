# Account and Login Troubleshooting

## Purpose

This guide outlines a basic troubleshooting process for common account access and login issues in a workplace environment.

The goal is to determine whether the issue is related to credentials, multi factor authentication, account status, permissions, or a larger system problem.

## Common Symptoms

A user may report:

* Incorrect password errors
* Account locked messages
* Unable to complete multi factor authentication
* Access denied messages
* Login works for one system but not another
* Password reset not working
* User can log in but cannot access required resources

## Troubleshooting Steps

### 1. Confirm the Issue

Ask the user what happens when they attempt to log in.

Useful questions include:

* What system or application are you trying to access?
* What error message do you see?
* When did you last successfully log in?
* Did you recently change your password?
* Are you able to access other company systems?
* Are other users experiencing the same issue?

Avoid asking the user to share their password.

### 2. Confirm the Correct Account

Verify that the user is entering the correct username, email address, or company account.

Users may have multiple personal and work accounts saved on the same device.

### 3. Check Basic Credential Issues

Confirm that Caps Lock is not enabled.

Check for typing errors in the username or email address.

If the user recently changed their password, confirm that they are using the new password.

### 4. Attempt a Password Reset

If appropriate, direct the user to the approved password reset process.

Confirm that the reset email or verification message is being delivered successfully.

After the reset, have the user attempt to log in again.

### 5. Check Multi Factor Authentication

If the password is accepted but the user cannot complete login, review the multi factor authentication step.

Possible issues include:

* Verification code not arriving
* Authenticator application not updating
* Old phone number registered to the account
* New device requiring verification
* Time synchronization issue on the device

If the authentication method cannot be updated by the user, escalate to the appropriate administrator.

### 6. Check Account Status

An administrator may need to confirm whether the account is:

* Active
* Locked
* Disabled
* Expired
* Missing required permissions

Account status changes should only be performed by authorized personnel.

### 7. Check Permissions

If the user can log in but cannot access a specific folder, application, or resource, the issue may be related to permissions rather than authentication.

Confirm which resource the user needs and what level of access is expected.

## Security Considerations

Never ask a user to send or disclose their password.

Verify the user's identity according to company procedures before making account changes.

Do not bypass security controls simply to restore access.

Report suspicious login activity or unexpected authentication prompts according to company security procedures.

## Escalation

Escalate the issue when:

* The account remains locked after standard troubleshooting
* Administrative permissions are required
* Multi factor authentication must be reset
* The user appears to have incorrect permissions
* Suspicious account activity is detected
* Multiple users cannot access the same system
* The problem may involve a company wide authentication service

## Example Ticket Notes

**Issue:** User unable to access company application after changing password.

**Troubleshooting completed:** Confirmed correct username, verified the user was entering the new password, tested access to another company system, and confirmed multi factor authentication was working.

**Result:** User could access other systems but continued receiving an access denied message in the affected application.

**Next step:** Escalated to the application administrator to review permissions.

## Key Takeaway

Login problems are not always password problems. A structured troubleshooting process helps separate credential issues from authentication, account status, permissions, and system availability problems.
