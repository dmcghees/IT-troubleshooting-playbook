# WiFi and Network Connectivity Troubleshooting

## Purpose

This guide outlines a basic troubleshooting process for common workplace WiFi and network connectivity issues.

The goal is to identify whether the problem is related to the user's device, the wireless connection, network settings, or a larger infrastructure issue.

## Common Symptoms

A user may report:

* No internet connection
* Connected to WiFi but unable to access websites
* Slow or unstable connection
* Frequent disconnects
* Unable to connect to the workplace network
* One application working while another cannot connect

## Troubleshooting Steps

### 1. Confirm the Problem

Ask the user what they are experiencing.

Useful questions include:

* Are you completely disconnected, or is the connection just slow?
* Can you access any websites or applications?
* Is the issue happening on one device or multiple devices?
* Did the problem start recently?
* Are other people nearby experiencing the same issue?

This helps determine whether the issue is isolated or may involve the broader network.

### 2. Check Basic Connectivity

Confirm that WiFi is turned on and that the device is connected to the correct network.

Check whether airplane mode is enabled.

If necessary, disconnect from the WiFi network and reconnect.

### 3. Test the Connection

Try opening more than one website or application.

This helps determine whether the issue is affecting the entire connection or only a specific service.

If available, test another device on the same network.

### 4. Restart the Connection

Turn WiFi off and back on.

If the issue continues, restart the device.

A restart can clear temporary network or operating system issues.

### 5. Forget and Rejoin the Network

If the device continues having trouble connecting, remove the saved WiFi network and reconnect using the correct credentials.

This can help when stored network settings are outdated or corrupted.

### 6. Check Network Configuration

Review the device's network settings.

Confirm that the device is receiving an IP address and that there are no obvious configuration errors.

For more advanced troubleshooting, tools such as `ipconfig`, `ping`, or `traceroute` may be used to gather additional information.

### 7. Determine Whether the Issue Is Widespread

If several users are reporting similar problems, the issue may involve the wireless access point, network hardware, internet service provider, or another shared system.

Document how many users or areas appear to be affected.

## Escalation

Escalate the issue when:

* Multiple users are affected
* The device cannot obtain a network connection after basic troubleshooting
* Network hardware may be involved
* Administrative access is required
* The issue involves security settings or restricted systems
* The issue continues after standard troubleshooting steps

When escalating, provide clear documentation of the symptoms and all troubleshooting steps already completed.

## Example Ticket Notes

**Issue:** User unable to access the internet while connected to workplace WiFi.

**Troubleshooting completed:** Confirmed correct WiFi network, checked airplane mode, disconnected and reconnected to WiFi, restarted device, and tested multiple websites.

**Result:** Issue continued after basic troubleshooting.

**Next step:** Escalated to network support for further investigation.

## Key Takeaway

A structured troubleshooting process helps avoid unnecessary changes and makes it easier to identify whether the issue is related to the user, the device, or the larger network environment.
